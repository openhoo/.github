## HooStack

Our toolkit for code quality, security, releases, and local development.

| Project | What it does |
| --- | --- |
| [Hoonarqube](https://github.com/openhoo/hoonarqube) | Static analysis across seven languages. |
| [HooSharper](https://github.com/openhoo/hoosharper) | Roslyn analyzers and C# code fixes. |
| [Hooray](https://github.com/openhoo/hooray) | Vulnerability and software supply-chain scanning. |
| [Hoolicy](https://github.com/openhoo/hoolicy) | Repository policy as code. |
| [Hooversion](https://github.com/openhoo/hooversion) | Commit linting and automated releases. |
| [HooNeedsUpdates](https://github.com/openhoo/hooneedsupdates) | Dependency update plans and pull requests. |
| [Hoocloak](https://github.com/openhoo/hoocloak) | OpenID Connect for local development and tests. |
| [Hoomail](https://github.com/openhoo/hoomail) | Email testing with a local inbox and message inspection. |
